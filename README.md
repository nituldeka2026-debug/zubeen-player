# Zubeen Radio — Responsive UI

Responsive computer + mobile radio interface based on the supplied Zubeen artwork.

## Files
- `index.html` — main page
- `style.css` — desktop + mobile responsive styling
- `app.js` — clock and demo play-state UI
- `assets/zubeen-bg.jpg` — supplied background artwork

## Real audio
The demo play button only changes the UI state. To connect a real radio stream, add your direct MP3/AAC/HLS stream to a native `<audio>` element. A YouTube video ID alone does not guarantee mobile background playback.
